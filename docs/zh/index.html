田粲 Can Tian

北卡罗来纳大学教堂山分校 经济系 副教授

我是一名宏观经济学家，研究单个企业的行为如何加总为宏观经济：企业为何在规模和生产率上存在差异，企业如何成长、进入与退出，企业之间如何建立并利用联系，以及这些对长期增长和短期波动意味着什么。

研究方向：宏观经济学、企业间网络（生产网络、知识网络）的形成与演化、企业异质性与动态、创新与增长、搜寻与匹配理论、经济周期、信息摩擦。
